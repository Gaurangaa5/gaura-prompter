# GauraPrompter 🎬

GauraPrompter is a lightweight, modern, and completely offline teleprompter web application inspired by CuePrompter. Built with a sleek blue theme and clean Inter typography, it allows users to paste scripts, customize readability settings, and control scrolling seamlessly using keyboard shortcuts.

## ✨ Features
* **100% Offline-Capable:** Runs entirely in your local browser with no external server dependencies.
* **Modern Blue Aesthetics:** Designed with a dark interface paired with clean, professional blue accents.
* **Fully Customizable:** Adjust font sizes, text alignments, text colors, and background backdrops instantly.
* **Keyboard Hotkeys:** Control your presentation effortlessly without touching the mouse.
* **Mirror Flip Mode:** Invert text vertically for physical glass teleprompter rig setups.

## ⌨️ Keyboard Shortcuts
* `Spacebar` - Play / Pause scrolling
* `Arrow Up` - Increase scroll speed
* `Arrow Down` - Decrease scroll speed
* `F` - Mirror/Flip text vertically
* `Escape` - Exit prompter and back to setup dashboard

## 🚀 Getting Started
1. Download or clone this repository.
2. Double-click `index.html` to open it in any web browser.
3. Paste your script, adjust your settings, and hit **Start Prompter**!
