About GauraPrompter

GauraPrompter

Version 2.0.0

An enterprise-grade, offline-first web teleprompter solution built for high-performance scripting, presentations, video editing, and public speaking.

Running entirely inside your browser's execution thread, your data is secure, processed locally, and never touches remote servers. Zero external runtime dependencies ensures system consistency, stability, and maximum uptime.

Keyboard Shortcuts

  • Space Play / Pause Scroller Engine
  • Arrow Up Increase Engine Scroll Speed (+1)
  • Arrow Down Decrease Engine Scroll Speed (-1)
  • Arrow Left Micro-scroll Upward Slightly
  • Arrow Right Micro-scroll Downward Slightly
  • M Toggle Mirror Mode (Horizontal Flip)
  • V Toggle Vertical Flip Direction
  • H Force Hide / Show All HUD Overlay Controls
  • R Reset Prompter Layout Position to Top
  • F Toggle Fullscreen Display State
  • ESC Exit Back to Main Script Dashboard
  • ? Open Keyboard Shortcuts Panel
